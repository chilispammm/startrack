# 📊 Football Talent Valuation (AFCON 2023 Case Study)

## 🚀 Overview

This project explores **data-driven player valuation** in African football using **AFCON 2023** as a case study.
By integrating **event data (StatsBomb)** and **market values (Transfermarkt)**, we build a pipeline that:

* Cleans and standardizes player performance data.
* Engineers football-specific features (e.g., xG, progressive passes, Expected Threat).
* Trains machine learning models to predict **player market value**.
* Deploys an **interactive Streamlit app** for scouting and player comparison.

---

## 🔧 Tech Stack

* **Python**: data cleaning, feature engineering, modeling.
* **Libraries**: pandas, scikit-learn, XGBoost, SHAP, matplotlib, seaborn.
* **Streamlit**: web app for scouting & valuation demos.
* **Data Sources**:

  * [StatsBomb](https://statsbomb.com/) (AFCON 2023 events)
  * [SofaScore](https://www.sofascore.com/) (player stats)
  * [Transfermarkt](https://www.transfermarkt.com/) (market value, contracts, injuries)
